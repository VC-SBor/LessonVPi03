# Callback API (VKBottle)

Локальная копия документации VKBottle по Callback API. Все примеры кода скопированы дословно со страниц-источников.

## Callback (интерфейсы низкого уровня)

Источник: https://vkbottle.readthedocs.io/ru/latest/low-level/callback/

### Общее описание

Для поддержки `Callback API` реализован абстрактный класс `ABCCallback`, на основе которого вы можете сделать свою реализацию.

### Работа с CallbackAPI

Методы работы с Callback API (управление серверами в сообществе ВКонтакте):

#### add_callback_server

Добавляет сервер в вашу группу вк.

#### delete_callback_server

Удаляет сервер по `server_id`

#### edit_callback_server

Редактирует настройки существующего сервера по `server_id`

#### get_callback_confirmation_code

Получает код, необходимый для подтверждения вашего сервера

#### get_callback_servers

Получает список серверов, подключенных к сообществу

#### get_callback_settings

Получает список событий для указанного сервера по `server_id`

#### set_callback_settings

Устанавливает список событий для указанного сервера по `server_id`

#### construct

Принимает API, нужно для того чтобы конструировать поллинг с обновленным API при каждом вызове. Возвращает собственный инстанс, может быть использован в билдер интерфейсе

### Параметры для BotCallback

- **url** - сервер, на который будут отправляться события
- **title** - короткое имя сервера, которое будет показываться в настройках сообщества
- **secret_key** - секретный ключ, по которому можно достоверно определить, что сообщение пришло именно от вашего бота. По умолчанию генерируется произвольная строка.
- **api** - если не указано, будет получен автоматически при создании объекта
- **group_id** - если не указано, будет автоматически получен при установке сервера

### Создание кастомного клиента

Ваша реализация должна наследоваться от `ABCCallback` и имплементировать вышеуказанные методы.

> Примечание: на этой странице нет примеров кода — перечислены только сигнатуры/описания методов и параметры.

## Подключение CallbackAPI (туториал)

Источник: https://vkbottle.readthedocs.io/ru/latest/tutorial/callback-bot/

### Предупреждения и требования

> **Внимание**
>
> **[Обязательно к прочтению](https://dev.vk.ru/api/callback/getting-started)**
>
> У вас должен иметься собственный сервер с доменным именем. DDNS работать не будет.
> Также подразумевается наличие опыта в настройке веб-серверов.

### Полный процесс подключения

Для подключения `CallbackAPI` к вашему сообществу:

1. Инициализировать параметры для настройки, например, таким образом:

```python
import os
TOKEN = os.getenv("VK_TOKEN") # ключ сообщества
url = os.getenv("VK_URL") # url = "http://example.com/whateveryouwnant"
title = os.getenv("VK_TITLE") # title = "server"
secret_key = os.getenv("VK_SECRET_KEY") # опционально
```

2. Импортировать `BotCallback` из `vkbottle.callback` и указать параметры для настройки:

```python
from vkbottle.callback import BotCallback
callback = BotCallback(
    url = url,
    title = title
)
```

3. Инициализировать бота:

```python
from vkbottle import Bot
bot = Bot(token=TOKEN, callback=callback)
```

4. Настроить любой сервер (`aiohttp`, `flask`, `fastapi`) и обрабатывать полученные события. Для более полного ознакомления рекомендуется посмотреть пример.

```python
# event - событие, полученное от vk
await bot.process_event(event)
```

> **Внимание**
>
> После подключения бот будет обрабатывать входящие сообщения, для получения остальных событий необходимо включить их в настройках группы.

## Ключевые моменты (сводка по страницам)

- **Что такое Callback API**: механизм, при котором ВКонтакте сама отправляет события (сообщения и другие события сообщества) на ваш сервер по указанному URL, вместо того чтобы бот опрашивал ВК. Отсюда требование иметь собственный сервер с доменным именем (DDNS не поддерживается) и опыт настройки веб-серверов.
- **Отличие от LongPoll**: при Callback события приходят push-запросами на ваш `url` (нужен публичный сервер и обработка входящих HTTP-запросов), в то время как при LongPoll/Polling бот сам опрашивает ВКонтакте о новых событиях (страница [Polling](https://vkbottle.readthedocs.io/ru/latest/low-level/polling/) в документации — соседняя с Callback). Сами страницы подробного сравнения с LongPoll не приводят.
- **Реализация в VKBottle**: абстрактный класс `ABCCallback` (низкоуровневый интерфейс) и готовая реализация `BotCallback` из `vkbottle.callback`, передаваемая в `Bot(..., callback=callback)`.
- **Ключевые параметры настройки**: `url` (сервер приёма событий), `title` (короткое имя сервера в настройках сообщества), `secret_key` (секретный ключ для проверки, что событие пришло от вашего бота; по умолчанию генерируется произвольная строка), `api` (получается автоматически), `group_id` (получается автоматически при установке сервера), `TOKEN` (ключ сообщества).
- **Confirmation token / подтверждение сервера**: метод `get_callback_confirmation_code` получает код, необходимый для подтверждения сервера; управление серверами сообщества (`add`/`edit`/`delete`/`get_callback_servers`) и настройкой событий (`get_callback_settings`/`set_callback_settings`) выполняется методами `ABCCallback`.
- **Полный процесс подключения**: (1) параметры из переменных окружения → (2) `BotCallback(url=..., title=...)` → (3) `Bot(token=TOKEN, callback=callback)` → (4) веб-сервер (`aiohttp`, `flask`, `fastapi`) принимает события и передаёт их в `await bot.process_event(event)`.
- **Включение событий**: после подключения бот по умолчанию обрабатывает входящие сообщения; остальные события нужно вручную включить в настройках сообщества (метод `set_callback_settings`).
- **Кастомная реализация**: наследуйтесь от `ABCCallback` и имплементируйте описанные выше методы.
